## このサイトについて

- **技術**：HTML / CSS / JavaScript（ライブラリ不使用）
- **動き**：ローディング、見出しの1文字送り、スクロール連動の出現、数字のカウントアップ、カードの3D切り替え。いずれも外部ライブラリを使わず `assets/style.css` と `assets/motion.js` だけで組んでいます
- **AIに読まれることを想定した対応**：JSON-LD（構造化データ）・llms.txt・OGP・sitemap.xml
- **アクセシビリティ**：タブ操作・キーボード操作に対応、`prefers-reduced-motion` で動きを抑制
- **公開**：GitHub Pages
